# Лабораторна робота №11 — інтернет-магазин і Telegram-бот «Лілея»

**Автор:** [ПІБ студента], група [група]

## Що зроблено
- **Інтернет-магазин** (сайт Лаби 2 + кошик на JavaScript): кнопки «+ У кошик» на картках і сторінках товарів (з урахуванням об'єму/відтінку), лічильник у шапці, сторінка `cart.html` (кількість, видалення, сума в грн і ≈€), збереження в `localStorage`.
- **Каталог:** 26 товарів у 7 розділах — фото (SVG), опис, склад, ціна.
- **Доставка (3 методи):** Нова Пошта — відділення/поштомат **і** адресна доставка кур'єром; Укрпошта; **самовивіз** — м. Київ, вул. Саксаганського, 41 (ст. м. «Університет»).
- **Онлайн-оплата WayForPay:** кнопка «Оплатити через WayForPay» формує замовлення з підписом HMAC-MD5 і відкриває справжню сторінку оплати WayForPay (Visa/Mastercard, Apple Pay, Google Pay). Зараз — **тестовий режим** через публічний тестовий мерчант `test_merch_n1`; тестові картки `4111 1111 1111 1111` / `5454 5454 5454 5454`, будь-який майбутній термін і CVV.
- **Правила доставки та оплати** — сторінка `rules/index.html` (посилання є в кошику, у формі оформлення й у боті).
- **Telegram-бот** — код `bot/worker.js` для Cloudflare Workers: `/start`, `/catalog`, `/rules`, `/contacts`, кнопка **«🛍 Відкрити магазин»** (Telegram Web App — магазин із кошиком і оплатою відкривається прямо в Telegram).
- `assets/logo_640.png`, `assets/banner_1200x400.jpg` — логотип і банер для магазину / бота.
